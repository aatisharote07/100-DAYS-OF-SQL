# Day 24: SQL Challenge - Subqueries (Percentage of Group Total)

## 📌 Business Scenario
A retail sales director wants to analyze employee performance. They need to understand how much each individual salesperson contributed to their department's total sales volume. 

The output report must show each salesperson's name, department, individual sales, and the percentage of the department's total sales they generated.

---

## 🗄️ The Schema

### Table Structure & Sample Data

```sql
-- Create Sales Performance Table
CREATE TABLE sales_performance (
    salesperson_id INT PRIMARY KEY,
    salesperson_name VARCHAR(100),
    department VARCHAR(50),
    sales_amount DECIMAL(10, 2)
);

-- Insert Sample Data
INSERT INTO sales_performance (salesperson_id, salesperson_name, department, sales_amount) VALUES
(1, 'Alice Smith', 'Electronics', 15000.00),
(2, 'Bob Jones', 'Electronics', 25000.00),
(3, 'Charlie Brown', 'Electronics', 10000.00), -- Electronics Total: 50,000
(4, 'David Green', 'Furniture', 30000.00),
(5, 'Emma White', 'Furniture', 20000.00);      -- Furniture Total: 50,000
```

---

## ❓ The Question
Write an SQL query to calculate the percentage of the department's total sales generated by each salesperson. Return the `salesperson_name`, `department`, `sales_amount`, and `dept_sales_percentage` (rounded to 2 decimal places). Order the results by department and then by percentage contribution descending.

---

## 💡 The Solution

### Method 1: Using a Correlated Subquery (Standard ANSI SQL)
```sql
SELECT 
    sp1.salesperson_name,
    sp1.department,
    sp1.sales_amount,
    ROUND(
        sp1.sales_amount * 100.0 / (
            SELECT SUM(sp2.sales_amount)
            FROM sales_performance sp2
            WHERE sp2.department = sp1.department
        ),
        2
    ) AS dept_sales_percentage
FROM sales_performance sp1
ORDER BY sp1.department, dept_sales_percentage DESC;
```

### Method 2: Using Window Functions (Alternative)
```sql
SELECT 
    salesperson_name,
    department,
    sales_amount,
    ROUND(
        sales_amount * 100.0 / SUM(sales_amount) OVER (PARTITION BY department),
        2
    ) AS dept_sales_percentage
FROM sales_performance
ORDER BY department, dept_sales_percentage DESC;
```

---

## 📝 Explanation
- **Correlated Subquery (Method 1)**: The subquery inside the `SELECT` list dynamically sums the sales of all employees who belong to the same department as the salesperson in the current outer row (`sp2.department = sp1.department`). 
- **Window Function (Method 2)**: The window function `SUM(sales_amount) OVER (PARTITION BY department)` computes the department total inline without requiring a subquery, which can be cleaner and faster on modern database engines.
- **Percentage Formula**: Dividing the salesperson's individual `sales_amount` by the department total and multiplying by `100.0` yields the ratio, which is then formatted to 2 decimal places using `ROUND()`.
